# Investor persona catalog

Choose one starting lens; these are interpretations of published investment approaches, not the named investors or their endorsements. Their names do not establish predictive skill. Read only the selected persona reference. Create distinct personal sources when comparing lenses; one analysis selects one exact Brain.
